# YY & ZZ Love Space

一个使用 Vue 3、TypeScript、Vite、Vue Router 与 Vue I18n 构建的轻量响应式爱情空间网站，支持中文、英文和明暗双主题。

## 中英文访问

- 中文首页：`#/zh`
- 英文首页：`#/en`
- 访问根地址时，会优先采用上次选择的语言；首次访问则根据浏览器语言自动选择。
- 切换语言时会保留当前页面；例如英文还愿详情会切换到同一篇中文详情。

## 开发与构建

```bash
npm install
npm run dev
npm run type-check
npm run build
```

构建产物位于 `dist/`，可由项目内的 Nginx 配置提供静态访问。

│   ├── VowBarrage.vue          # 还愿清单弹幕

## 添加还愿记录

在 `src/content/vows/zh-CN/` 新建中文 `.md`，并在 `src/content/vows/en-US/` 新建同名英文 `.md`。文件名会成为详情页地址，两个目录内的同名文件会在语言切换时互相对应；项目重新构建后会自动生成弹幕。

```md
---
title: 去一座陌生的海边城市
summary: 写在详情页标题下方的一句话。
date: 2026-09-10
status: 心愿中
order: 4
---

这里开始写 Markdown 正文。
```

正文支持标题、列表、引用、链接和图片。图片可以放在对应语言目录内的 `images/` 子目录，并在 Markdown 中使用相对路径，例如 `![图片说明](./images/example.webp)`。为保护隐私，真实图片发布前请先完成像素化或油画风处理并清除 EXIF 信息。

如果暂时只添加了中文文件，英文还愿清单会回退展示该篇中文内容，避免详情链接失效；补齐同名英文文件后会自动替换为英文版本。

## 隐私约定

- 公开页面只使用 `YY`、`ZZ` 两个代号。
- 地图只保存城市中心点，不保存住址、精确位置或实时轨迹。
- 照片加入仓库前应先像素化或风格化，并清除 EXIF 信息。
- 添加时间线照片的方法见 `src/assets/memories/README.md`。
- Map My Visitors 是 Footer 中可见的第三方访客地图；原 Flag Counter 仅视觉隐藏并继续统计。加载页面时，访客浏览器会连接这两个第三方服务。
